Ligar ao teu GitHub

Só tens de fazer isto uma vez em cada dispositivo. A chave fica guardada apenas neste browser, e sem ela ninguém consegue mexer nas músicas, mesmo que encontre esta página.

  1. Carrega em Criar chave no GitHub (abre num separador novo).
  2. Em Repository access escolhe Only select repositories e seleciona o repositório do site.
  3. Desce até ao fim, carrega em Generate token e copia a chave (começa por github_pat_).
  4. Cola-a aqui em baixo.
